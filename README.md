# UsabilityHub Clone
For my first Web Dev project, I set out to clone the UsabilityHub website using HTML and CSS. This project aimed to replicate the core features and layout of the original site, providing a hands-on experience in web design and development.

## 📍Objectives :
- Learn and apply HTML and CSS
- Build a responsive design
- Replicate key features
